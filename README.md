# Tree Management and Care Tracking System

## About
ระบบจัดการและติดตามดูแลต้นไม้ เป็นระบบที่ช่วยจัดการข้อมูลต้นไม้
และติดตามการดูแลต้นไม้แต่ละต้นอย่างเป็นระบบ เช่น การรดน้ำ
การใส่ปุ๋ย และประวัติการดูแล

## Features
- เพิ่ม แก้ไข และลบข้อมูลต้นไม้
- แสดงรายละเอียดของต้นไม้
- บันทึกข้อมูลการดูแลต้นไม้
- ติดตามประวัติการดูแลต้นไม้
- จัดการข้อมูลต้นไม้อย่างเป็นระบบ

## Objectives
เพื่อพัฒนาระบบที่ช่วยจัดการข้อมูลและติดตามการดูแลต้นไม้
ให้สะดวก เป็นระบบ และช่วยลดความยุ่งยากในการบันทึกข้อมูล
